### 3.4 评测方法自身的两点局限（判读时须知）

- 判分只看锚点是否出现，不校验语义正确——Q4 场景已实证过关键词 gate 可被幻觉内容骗过；
- 题库 20 题规模小，问答层单题存在 LLM 逐次方差（±1 题正常波动），结论以「层次差异 + 出处归因」为主，不抠单题。

## 四、检索工程四轮迭代（经验，剩余 8 图直接复用）

| # | 问题 | 修法 | 效果 |
|---|---|---|---|
| 1 | markdown 大表被 naive 解析器渲染为**单体 10238 字符 `<table>` chunk**，向量化截断，深层行永久不可检索 | 长表拆为逐行 bullet/QA，单切片 ≤330 字符 | 值行重新可召回 |
| 2 | 查询「米/万立方米」vs 图表「m/万m³」**词形失配**，全文检索零命中 | 每行携带双词形（`786.00 米（786.00 m）`） | 词形通道打通 |
| 3 | 值密集行向量分互相打架，自然问句检索不到 | 逐值 `问：…？答：…` 行，自然问句近乎逐字命中 | C2 修至 rank 1；V1 曾至 rank 1（0.602） |
| 4 | 239 行 QA 反向**挤占**：特征水位类问句的 PDF chunk 被挤出 chat top-n（P1/P2 连锁挂） | 删冗余原始行、只留 QA 形态，控制单文档切片数（110→62） | P 侧恢复（top-10 特征水位 chunk 6 个、QA 行 0 个） |

另：切片级 `important_keywords` 打数值（59 片）对排序**无效果**——已实测排除。

## 五、RAGFlow v0.27.1 已探明的行为特性

1. naive 解析器把 markdown 表格渲染成 HTML 后**不再按 chunk_token_num 切分**（单体表无大小上限）；
2. 混合打分（向量+关键词）中，**自然问句里的小数数值 token 不产生可区分的 keyword 得分**——大量同构行切片平分，exact 行排序靠向量噪声；纯数值查询则走精确词元、rank 1 确定；
3. `/retrieval` 返回的 chunk 无 `document_name` 字段（completions 引用里是 `document_name`，检索响应需用 `content` 判文档归属或另行 join）；
4. chat 问答层的召回管线与 `/retrieval` 端点参数不完全一致（V1 曾出现检索层 miss、问答层 pass），对偶评测必须两层都跑。

## 六、后续优化方案

### 6.1 短期（下一批导入前，低成本高收益）

1. **剩余 8 图按第四节经验直接产出融合文本**：小表（≤20 行）可保留 markdown 表格；大表一律逐值 QA 行；曲线类带 `±5% 视觉近似` 标注；逐值打 `important_keywords`（虽不影响排序，利于 QC 审计）。
2. **扩题库口径**：纯数值查询题（`786.00` 式）作为「值可达性」层单独计分，与自然问句层分开汇报，避免把打分器特性误读为数据缺失。
3. **每次 after 评测跑 2 轮取并集**，对冲 LLM 方差（P2 类波动即可显性化）。

### 6.2 中期（小数表格行检索的根治）

4. **改用 Table chunk_method** 导入库容表：RAGFlow 对结构化表格做行级单元+数值索引，是 239 行值表的本命解析路径；导入后与现有 QA 行文档并存，用题库对比两条路径的 rank 稳定性，择优保留。
5. **调 chat 助手 top_n（8→12/16）**：同构平分场景下扩大喂给 LLM 的切片窗口，提升 V1 类题的问答命中率；若采纳，before/after 基线需同配置重跑以保持对照有效性。
6. **关键词权重调整实验**：chat 助手 `keywords_similarity_weight` 上调一档做 A/B（同题库、同轮次双跑），验证对小数行排序的实际增益后再定稿。

### 6.3 数据治理（独立于检索优化）

7. **两组库内矛盾仲裁**：校核洪水位 790.30（读图 2/3 票）vs 790.5（批复文）；死水位 762.80（读图+查对表自洽）vs 755.00（另有文本）。路径：高分辨率重扫 02-大坝剖面图 → 复跑 VLM 三方 → 若与批复文冲突，以批复文为准修订融合文档并全库注记。
8. **校准题回归**：现有 QC 六问 + 本 20 题合并为回归题库，任何 KB 结构调整（Table 方法切换、top_n 调整、矛盾修订）后全量复跑，防止此轮增益被回退。

### 6.4 优先级建议

按收益/成本排序：**6.1-1（8 图复用导入）> 6.3-7（矛盾仲裁，影响数据可信度）> 6.2-4（Table 方法实验）> 6.1-2/3（评测口径）> 6.2-5/6（助手参数）**。
